# Workflow

## Scope and modes

Use the user's current request, not an automatic end-to-end pipeline. A request to
discuss style authorizes discussion, not a sample chapter. A request to research
authorizes collecting sources, not publishing. Once drafting is authorized, do not
seek confirmation before every routine paragraph or image placement.

## Project records

- `book.yaml`: audience, scope, language, profiles, layout and source cutoff.
- `decisions.md`: dated decisions, superseded decisions, pending questions.
- `state.yaml`: current task, chapter status, unresolved issues, next steps and
  plugin/schema version. An empty chapter list is valid before drafting.
- `outline.md`: substantive topics, sequencing, prerequisites and intended examples.
- `terms.yaml`: canonical terminology, accessible explanation and first-use section.
- `evidence.yaml`: claims, precise source locators, checks and affected sections.
- `image-index.yaml` and `table-index.yaml`: assets, positions and layout intentions.

Read project files instead of relying on chat history. Update concise records after
substantive changes; never copy the whole conversation or inflate the memory files.

## Outline and drafting

Design topics from foundations to application; maintain one principal explanation
per concept and use cross-references elsewhere. Identify likely illustrations when
outlining. Assign depth according to difficulty and use, not fixed word quotas.
Do not force learning objectives or introductions into chapters if the profile
places them in the front matter. Keep methods, supporting images and examples together.

## Editorial passes

1. Content: scope, factual support, limitations and conditions of application.
2. Structure: ordering, duplication, definitions and connections between chapters.
3. Language: clarity, unnecessary words, terminology, grammar and Vietnamese diacritics.
4. Visuals: evidence, readability, captions, placement, source and layout fallback.

These are review passes, not a requirement to launch separate agents. Record which
passes were performed and what remains. Use subagents only when authorized.
