# Maintaining Authoring Studio

This repository contains a reusable plugin, not a book manuscript. Do not create
book chapters or copy user-owned book assets here. Put temporary test projects in
the operating system temporary directory. Keep the rural-tourism configuration a
named profile; do not impose its locale or content on unrelated books.

Preserve the user's decisions in the profile history. Pending choices are not
approvals. Table captions and every first-row header cell are centred; this rule
does not centre chapter/section headings. Keep scripts portable and paths relative.

When changing schemas or helpers, run the source tests and repository validator.
For releases, synchronize both manifests, CHANGELOG and the release note; build
the deterministic archive. Never move a published version tag. No automatic book
migration, silent global installs, GitHub push or publication as part of writing.

Do not add placeholder skills. The presentation skill is planned, not implemented.
