# Authoring Studio 0.1.0

Bản đầu gồm skill write-book, quy trình biên soạn từ Markdown/YAML, hồ sơ quy ước
của giáo trình du lịch, quản lý ảnh/bảng/nguồn và trạng thái dự án.

Có helper khởi tạo không ghi đè, validator chỉ đọc, bộ kiểm thử và ZIP plugin
kèm SHA256. Có marketplace để chuẩn bị cài từ kho GitHub và bản manifest tương thích.

Chưa có nội dung sách, skill trình chiếu, renderer, chuyển đổi schema hoặc tự cập
nhật. Cấu hình dàn trang chưa phải kết quả đã được render. Kiểm thử hành vi bằng
model và cài đặt đa tài khoản chưa được xác nhận. CI đa hệ điều hành chạy sau khi
đưa kho lên GitHub, không coi cấu hình workflow là kết quả đã chạy.

Schema nguồn: 1. Phụ thuộc helper: Python 3.10+, PyYAML 6.0.3, jsonschema 4.25.1.
